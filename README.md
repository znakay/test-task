## Requirements
[ ]The layout must be responsive with a minimum display resolution of 320px. The adaptive design is at your discretion, but the page should display correctly in the browser at any resolution.

[ ]The layout should follow the structure and naming conventions of the BEM methodology.

[ ]Styles should use the SASS preprocessor in the SCSS dialect.

[ ]The finished layout must display correctly on the latest versions of all major browsers (Chrome, Firefox, Edge (Chromium), Safari) as well as their mobile counterparts.

[ ]The completed page and all resources should be optimized for "weight" and size.

[ ]Text, the number of items in the order form, and the number of form fields may change—the layout should account for this.

[ ]In the footer, payment systems should not be links, while contact information should be links.

[ ]The form should be prepared for functionality (each field should be input[name='...']).

[ ]The header should stick to the top of the page when scrolling.

[ ]The use of HTML/CSS frameworks or grid systems like Bootstrap is not allowed.

[ ]Proactivity in adding dynamic elements (animations, hover effects) is encouraged.

[ ]The use of third-party plugins for styling elements is allowed if necessary.

[ ]The completed test task should be uploaded to GitHub with a GitHub Pages deployment.
